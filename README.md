# Lung Disease Risk Predictor (learning project)

Predicts lung cancer risk level (Low / Medium / High) from symptom and
exposure ratings, with a planned 3D lung view and timeline.

**Not a medical tool.** For learning only.

## Data
Not included in this repository. Download "Cancer Patients and Air Pollution"
from Kaggle and save it as `data/raw/lung_cancer.csv`.
